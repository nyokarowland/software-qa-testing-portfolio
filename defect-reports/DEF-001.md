# Defect Report — DEF-001

## Defect Summary

**Defect ID:** DEF-001  
**Project:** Employee Service Request Portal  
**Related Test Case:** TC-REQ-002  
**Defect Title:** Service Request Can Be Submitted Without Required Category  
**Status:** Open  
**Severity:** Medium  
**Priority:** High  
**Environment:** Windows 11 / Microsoft Edge  
**Testing Method:** Manual Functional Testing

## Description

The Employee Service Request Portal allows a user to submit a new service request without selecting a request category, even though the Category field is defined as required.

Allowing requests to be submitted without a category may result in incomplete request information and could interfere with proper routing, reporting, or assignment of service requests.

## Preconditions

- User is logged into the application
- User has access to the New Request page

## Steps to Reproduce

1. Open the New Request page.
2. Leave the Category field blank.
3. Enter a subject.
4. Enter a description.
5. Select Submit.

## Test Data

**Category:** Blank  
**Subject:** Unable to access shared folder  
**Description:** Access to the department shared folder is unavailable.

## Expected Result

The application should prevent the service request from being submitted and display a validation message indicating that the Category field is required.

## Actual Result

The application accepts the service request without a category and generates a request number.

## Defect Impact

The defect allows incomplete service request records to enter the system. Missing category information could affect request routing, reporting accuracy, and the ability of support teams to identify the appropriate area responsible for resolving the request.

## Severity Justification

**Medium**

The defect affects application functionality and data quality but does not prevent the user from accessing the application or submitting a request. The request can still be created, although required information is missing.

## Priority Justification

**High**

The issue should be corrected promptly because the missing category may affect downstream request routing and operational processing.

## Recommended Correction

Add validation to the Category field so that:

- A category must be selected before submission
- The request is not saved when the Category field is blank
- A clear validation message informs the user that the field is required

## Retest Requirements

After the defect is corrected:

1. Repeat TC-REQ-002.
2. Verify that submission is blocked when Category is blank.
3. Verify that the required-field message displays.
4. Confirm that valid service requests can still be submitted.
5. Perform regression testing on related service request functions.
