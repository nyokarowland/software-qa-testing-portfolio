# Defect Report — DEF-002

## Defect Summary

**Defect ID:** DEF-002  
**Project:** Employee Service Request Portal  
**Related Test Case:** TC-PROFILE-002  
**Defect Title:** Profile Accepts Invalid Email Address Format  
**Status:** Resolved  
**Severity:** Medium  
**Priority:** Medium  
**Environment:** Windows 11 / Microsoft Edge  
**Testing Method:** Manual Functional Testing

## Description

The Employee Service Request Portal allows a user to save an improperly formatted email address in the profile section.

The email field accepts data that does not contain a valid email structure, which may result in inaccurate user contact information and could interfere with email-based notifications or communication.

## Preconditions

- User is logged into the application
- User has access to the Profile page

## Steps to Reproduce

1. Open the Profile page.
2. Replace the existing email address with an invalid email format.
3. Select Save.

## Test Data

**Email:** employee01example.com

## Expected Result

The application should reject the improperly formatted email address and display a validation message indicating that a valid email format is required.

## Actual Result

The application accepts and saves the improperly formatted email address.

## Defect Impact

The defect allows invalid email information to be stored in the user profile. Incorrect email data could affect system notifications, user communication, and the accuracy of account information.

## Severity Justification

**Medium**

The defect affects data validation and data quality but does not prevent the user from accessing or using the primary functions of the application.

## Priority Justification

**Medium**

The issue should be corrected during the normal development cycle because invalid email information could interfere with communication, but the defect does not prevent users from completing their primary tasks.

## Recommended Correction

Add email-format validation to the Profile page so that:

- The email field requires a valid email structure
- Invalid email addresses cannot be saved
- A clear validation message is displayed when the email format is invalid
- Valid email addresses continue to save successfully

## Retest Requirements

After the defect is corrected:

1. Repeat TC-PROFILE-002.
2. Verify that the invalid email address is rejected.
3. Verify that an appropriate validation message displays.
4. Confirm that valid email addresses can still be saved.
5. Perform regression testing on related profile functions.

## Resolution Verification

The defect was retested after the email-format validation correction was applied.

**Retest Result:** PASS  
**Final Status:** Resolved

The application now rejects improperly formatted email addresses and displays the expected email-format validation message. Valid email addresses continue to save successfully, and related profile functionality also passed regression testing.
